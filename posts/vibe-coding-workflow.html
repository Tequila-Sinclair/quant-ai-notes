如何利用 CLAUDE.md 打造高效的 AI 協同開發工作流

在進行 Vibe Coding 時，最常遇到的痛點就是：每次開啟新的對話框，AI 往往不清楚專案的歷史脈絡、UI 設計風格或檔案結構。透過引入標準化的 CLAUDE.md 規則文件，我們可以讓 AI 在每次讀取專案時，瞬間進入狀況。

1. 為什麼你需要一份 CLAUDE.md？

  • 統一設計系統： 規範網頁的 Tailwind CSS 顏色與排版，避免 AI 每次生成風格迥異的介面。
  • 明確檔案結構： 讓 AI 知道新增的頁面與文章該放在哪個資料夾（如 posts/）。
  • 減少溝通成本： 不需要每次都重新向 AI 解釋專案背景。

2. 實際運作成效

當有了這套規範後，未來只要告訴 AI：「幫我新增一篇關於 Python 量化交易的文章」，AI 就會自動依循 CLAUDE.md 中的規範來產出對應的 HTML 檔案，並同步更新首頁列表。
